# 🧩 Clase 05.1 – React: Estado, Eventos y Comunicación entre Componentes

## 🎯 Objetivo general  
Aprender a manejar **estado (`useState`)**, **eventos (`onClick`, `onChange`, `onSubmit`)** y **comunicación entre componentes (Padre ↔ Hijo)** en React, aplicando conceptos clave de la programación declarativa.

---

## 🧠 Contenidos principales  
- **useState:** manejo del estado en componentes funcionales.  
- **Eventos:** uso de `onClick`, `onChange` y `onSubmit` para interactuar con la interfaz.  
- **Renderizado dinámico:** actualización automática de la UI según el estado.  
- **Props:** paso de información y funciones entre componentes.  
- **Comunicación Padre ↔ Hijo:** ejecución de funciones del padre desde el hijo.  
- **Renderizado condicional:** cambio de estilos o contenido en función del estado.
